# F1 Live 0.2.3

Preview release for macOS 14 or later, supporting Apple-silicon and Intel Macs.

## Highlights

- Adds a compact, clickable **FANTASY LOCK** badge with a checkered flag beside Qualifying or Sprint. Clicking it opens the official F1 Fantasy website.
- Adds **Settings → Display → Show F1 Fantasy deadline**, independent of notification permissions and reminder settings.
- Adds optional F1 Fantasy reminders 24 hours and 1 hour before team lock: Qualifying on normal weekends, or the Sprint on Sprint weekends. Session and Fantasy reminders can be enabled separately.
- Simplifies notification setup: first-time activation opens the native macOS permission dialog directly. If permission was previously denied, the switch opens Notification settings and finishes enabling the requested reminder when you return after allowing notifications.
- Removes the flashing permission-wait message and keeps the settings layout stable.

Fantasy display and notifications are both off by default for new installations. Existing notification preferences are preserved.

If you have version 0.2.0 or later, choose **Check for Updates…** in F1 Live to download and install this release. New users and users on 0.1.0 can install the universal ZIP using `INSTALL.md`.

## Known limitation

This preview is ad-hoc signed and not notarized. Follow `INSTALL.md` to approve its first launch through macOS Privacy & Security.
